<p>KanJiSON is a comprehensive repository of 2,136 Japanese kanji in JSON format, complete with their levels, example words, and sample sentences. It’s designed to be easily downloaded and used for web applications, mobile apps, or personal study.</p>

<p>You can use KanJiSON with the KanjiOS web app (kanjios.vercel.app) or integrate it into other learning platforms. It is also utilized by <b>Japonema</b>, a free website for learning Japanese.</p>

## Latest revision

The latest revision of **KanJiSON** is available for download. You can get the complete set of kanji JSON files in **kanjis.zip** from the [Releases page](https://github.com/daikiejp/testwebhook/releases/latest).

## Features

- Ready-to-use JSON format
- Includes kanji levels, vocabulary, and example sentences
- Free to download and use for educational purposes
- Compatible with web and mobile applications
